# Weather App

A responsive weather application that shows real-time weather for any city.

## Features
- Search weather by city name
- Shows temperature, humidity, wind speed and weather icon
- Error messages for invalid or empty city names
- Responsive design for mobile and desktop

## Technologies Used
HTML5, CSS3, JavaScript, jQuery, Fetch API, JSON, OpenWeatherMap API

## How to Run
1. Download or clone this repository.
2. Get a free API key from openweathermap.org.
3. Open `script.js` and replace `YOUR_API_KEY` with your key.
4. Open `index.html` in a browser.
